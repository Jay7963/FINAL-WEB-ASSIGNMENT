# Jayson Portfolio - Multi-Page Professional Website

## 📋 Project Overview

A comprehensive, multi-page portfolio website showcasing modern web development skills with HTML5, CSS3, JavaScript, and responsive design.

## 🎯 Key Features

- **5-page structure**: Home, About, Skills, Projects, Contact
- **Responsive design** with mobile-first approach
- **Dark/Light mode toggle** with localStorage persistence
- **Interactive elements** including skill progress bars and project filtering
- **Form validation** with real-time feedback
- **Cross-browser compatibility** and accessibility considerations

## 📁 Project Structure

```
portfolio/
├── index.html          # Home page
├── about.html          # Personal background
├── skills.html         # Technical skills showcase
├── projects.html       # Portfolio projects
├── contact.html        # Contact form
├── css/
│   └── styles.css      # Custom animations
├── js/
│   └── main.js         # JavaScript functionality
└── images/             # Image assets
```

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **Vanilla JavaScript (ES6+)** - Modern JavaScript with classes
- **Font Awesome** - Icon library
